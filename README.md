I focus on pixel-perfect interfaces, smooth animations, and performance-minded apps that feel good to use.

In my professional journey, I work as a Software Developer at **XIIA**, a tech venture builder. There I contribute to real products across web and mobile — turning designs into production-ready experiences, connecting APIs, and helping teams ship features that users actually enjoy.

Outside of work, I am always learning and building. Whether it is a new React Native animation, a cleaner Next.js architecture, or a small UI experiment, I treat every project as a chance to get better.
